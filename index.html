알아둘 점

왜 사이트 안에서 로그인하지 않나요?

브라우저 보안 정책과 Instagram의 접근 제한 때문에 GitHub Pages가 개인 Instagram 세션을 가져와 DM·스토리를 직접 표시할 수 없어. 인증 정보는 공식 사이트에서만 입력해.

스토리가 안 보인다면?

웹에서 스토리를 제공하지 않는 계정이나 변경된 레이아웃은 스크립트로 복구하지 못할 수 있어. Instagram 웹 원본에서 스토리가 먼저 표시되는지 확인해.
