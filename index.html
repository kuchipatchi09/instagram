화면 속 원형과 메시지 스켈레톤은 디자인 예시야. 실제 스토리·DM은 별도 서버에 배포한 Quietgram Remote 웹앱에서 제공을 시도해.

Quietgram Remote · 독립 웹앱

Instagram에 별도 확장 없이 로그인할 수 있는 원격 브라우저 실험 버전이야. GitHub Pages는 서버를 실행할 수 없어서, 먼저 Render에 개인 서버를 배포해야 해. 실제 Instagram 로그인 성공은 아직 검증하지 못했어.

01. 개인 서버 배포

2GB Render 서버(현재 안내 기준 월 약 미화 $25)와 16자 이상 Quietgram 접근 코드가 필요해. 비용 발생 전 본인이 승인해야 해.

Render에서 서버 배포 ↗
02. 배포된 Quietgram 주소 접속

배포 후 받은 https://...onrender.com 주소를 입력해. 이 주소는 아래 기기에서 기억되며 외부로 전송되지 않아.

서버에서 직접 로그인

개인 접근 코드를 입력한 다음, 웹앱 내부에 표시되는 원격 Instagram 로그인 화면을 조작해. Instagram 암호를 이 홈페이지에는 입력하지 않아.

실험적 구현

원격 Chromium의 사진을 전송하는 방식으로 영상·오디오 경험이 제한되고, Instagram이 원격 로그인을 차단할 수 있어. 로그인 성공을 보장하지 않아.
