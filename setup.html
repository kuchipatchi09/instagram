Instagram에서 Quietgram.

이 페이지는 인스타그램 로그인 정보를 받지 않아. Safari 북마크에 작은 JavaScript 코드를 저장하고 공식 Instagram 사이트에서 실행하면 실제 스토리와 DM은 남긴 채 피드·릴스 영역을 숨길 수 있어.

Quietgram 북마클릿 만들기

코드는 이 저장소의 공개 소스를 이용해 브라우저 안에서 생성해. 다른 서버로 전송하지 않아.

  1. 이 페이지를 Safari 북마크에 추가해. 이름은 Quietgram으로 지정하면 편해.
  2. 위 코드 복사 버튼을 누른 다음, Safari 북마크 목록에서 방금 만든 북마크를 편집해.
  3. 북마크의 주소(URL)를 모두 지우고 복사한 코드로 바꾼 뒤 저장해.
  4. instagram.com 공식 로그인 화면에서 로그인해. 이미 로그인했다면 그대로 진행하면 돼.
  5. Instagram 홈에서 Safari의 북마크 목록을 열고 Quietgram 북마크를 눌러. 아래에 스토리/DM 버튼이 나타나.
Instagram 홈 열기 ↗DM 바로 열기 ↗

주의: 이 방식은 Quietgram의 별도 도메인 안에 Instagram 콘텐츠를 불러오는 것이 아니야. 로그인한 instagram.com 화면 자체를 변경하는 방식이고, 인스타그램이 웹페이지 구조를 바꾸면 작동하지 않을 수 있어. 페이지를 새로고침하거나 이동하면 다시 실행해야 할 수 있어. 특히 스토리 목록이 원래 웹사이트에도 표시되지 않는다면 생성할 수 없어.

Quietgram은 Instagram/Meta 공식 제품이 아니야. 비밀번호, 세션 쿠키, DM 내용을 Quietgram 서버에 수집하지 않아. 원하는 경우 코드를 검토할 수 있어.
